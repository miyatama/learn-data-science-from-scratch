# requirements.md

## 概要

Version 1.1.1 対応: ヘルプ情報に指定できるグラフタイプのリストを追加

## 変更・追加する機能の説明

`--help` / `-h` 実行時に表示されるヘルプ情報の `--type` オプション説明に、
指定できるグラフタイプ（line / bar / scatter / histogram）のリストを明示する。

## ユーザーストーリー

- ユーザーとして、`--help` を実行したときに `--type` で指定できる値の一覧を確認したい。

## 受け入れ基準

1. `--help` 実行時に `--type` の説明として指定可能な値（line, bar, scatter, histogram）が表示される
2. 既存の動作（グラフ生成）に影響を与えない
3. ビルド・テストが通ること

## 制約事項

- 言語: Rust（既存プロジェクトに追加）
- CLIフレームワーク: clap（既存）
