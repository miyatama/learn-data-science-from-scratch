# プロダクト要求定義書

## プロダクトビジョンと目的

JSONデータを入力として受け取り、折れ線・棒グラフ・散布図を画像として出力するRust製CLIツール。
データサイエンスの学習・実験用途で、手軽にデータを可視化できることを目的とする。

## ターゲットユーザーと課題・ニーズ

**ターゲットユーザー**
- データサイエンス学習者
- スクリプトやパイプラインでグラフ画像を生成したいエンジニア

**課題・ニーズ**
- PythonやRなしでコマンドラインからグラフ画像を生成したい
- JSONファイルや標準入力からデータを渡してグラフを出力したい
- CI/CDや自動化パイプラインに組み込める軽量なツールが欲しい

## 主要な機能一覧

1. 折れ線グラフ生成
2. 棒グラフ生成
3. 散布図生成
4. JSON形式のデータ入力（ファイル指定 / 標準入力）
5. 出力先ファイルパス指定
6. 出力画像サイズ指定

## 成功の定義

- JSONを入力として指定したグラフタイプの画像（PNG）が生成される
- コマンドラインオプションで出力先・サイズ・グラフタイプを制御できる
- 標準入力からのパイプ入力が動作する

## ビジネス要件

- Rustで実装する（学習目的のため）
- シングルバイナリとして動作する

## ユーザーストーリー

- データサイエンス学習者として、JSONファイルを渡すだけで折れ線グラフ画像を得たい
- エンジニアとして、パイプラインでデータを標準入力経由で渡しグラフ画像を自動生成したい
- 利用者として、画像サイズを指定して出力したい

## 受け入れ条件

- `--input` で指定したJSONファイルを読み込み画像を生成できる
- 標準入力からJSONを渡した場合も画像を生成できる
- `--output` で指定したパスにPNG画像が保存される
- `--size` で指定したピクセルサイズ（正方形）で画像が生成される
- `--type` で `line` / `bar` / `scatter` を指定できる
- デフォルト値: output=`./output/image.png`, size=`256`, type=`line`

## 機能要件

### CLIパラメータ

| オプション | 短縮形 | 型 | デフォルト | 説明 |
|---|---|---|---|---|
| `--output` | `-o` | string | `./output/image.png` | 出力先ファイルパス |
| `--size` | `-s` | int | `256` | 出力画像の一辺のピクセル数（正方形） |
| `--input` | `-i` | string(path) | なし（標準入力） | 入力JSONファイルパス |
| `--type` | `-t` | string | `line` | グラフタイプ（line / bar / scatter） |

### 入力JSONフォーマット

グラフタイプごとに入力JSONの構造を定義する（functional-design.mdで詳細定義）。

### 出力

- PNG形式の画像ファイル
- 出力先ディレクトリが存在しない場合は自動作成する

## 非機能要件

- シングルバイナリとして配布可能
- 依存クレートは必要最小限に留める
- エラー発生時は標準エラー出力にメッセージを出力し、非ゼロの終了コードを返す
