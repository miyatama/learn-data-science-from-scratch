# 要求内容 — Version 1.0.1 ヘルプオプション

## 変更・追加する機能の説明

`-h` / `--help` オプションでCLIのヘルプを表示できるようにする。
グローバルヘルプ（全コマンド一覧）とサブコマンド別ヘルプの両方を提供する。

## ユーザーストーリー

- 学習者として、`-h` または `--help` を実行して利用可能なコマンド一覧を確認したい
- 学習者として、各サブコマンドに `-h` / `--help` を付けて使い方を確認したい

## 受け入れ基準

- [ ] `cargo run -- -h` でグローバルヘルプを表示する
- [ ] `cargo run -- --help` でグローバルヘルプを表示する
- [ ] `cargo run -- add --help` で `add` コマンドのヘルプを表示する
- [ ] 各サブコマンド（`sub`, `scale`, `dot`, `sumsq`, `magnitude`）でも同様にヘルプを表示する
- [ ] `cargo test` が全て通過する

## 制約事項

- 外部クレート不使用（標準ライブラリのみ）
- 既存の演算機能を壊さない
