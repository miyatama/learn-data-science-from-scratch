# 要求内容 — Version 2.0.0 行列操作

## 変更・追加する機能の説明

行列を扱う新しいモジュールを追加し、行列の要素数（shape）を取得できるようにする。
CLIに `matrix` サブコマンドを追加する。

## ユーザーストーリー

- 学習者として、行列を入力してその shape（行数・列数）を確認したい

## 受け入れ基準

- [ ] `cargo run -- matrix shape "1,2,3;4,5,6"` → `(2, 3)`（2行3列）
- [ ] `cargo run -- matrix shape "1,2;3,4;5,6"` → `(3, 2)`（3行2列）
- [ ] 各行の列数が不一致の場合はエラーを返す
- [ ] `cargo run -- matrix --help` でヘルプを表示する
- [ ] `cargo test` が全て通過する

## 制約事項

- 外部クレート不使用（標準ライブラリのみ）
- 行列の要素型は `f64`
- 行の区切りは `;`、列の区切りは `,` とする
- 既存のベクトル演算機能を壊さない
