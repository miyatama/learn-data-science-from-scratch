# 要求内容 — Version 1.0.0 初回実装

## 変更・追加する機能の説明

Rustで線形代数のベクトル操作ライブラリとCLIを新規実装する。

## ユーザーストーリー

- 学習者として、CLIにベクトルを渡してベクトル加算・減算の結果を確認したい
- 学習者として、スカラー乗算を実行しベクトルの拡大縮小を確認したい
- 学習者として、内積を計算し2つのベクトルの関係を数値で確認したい
- 学習者として、二乗和・マグニチュードでベクトルの大きさを確認したい

## 受け入れ基準

- [ ] `cargo run -- add 1,2,3 4,5,6` → `[5, 7, 9]`
- [ ] `cargo run -- sub 5,7,9 4,5,6` → `[1, 2, 3]`
- [ ] `cargo run -- scale 2 1,2,3` → `[2, 4, 6]`
- [ ] `cargo run -- dot 1,2,3 4,5,6` → `32`
- [ ] `cargo run -- sumsq 1,2,3` → `14`
- [ ] `cargo run -- magnitude 3,4` → `5`
- [ ] 次元不一致時にエラーメッセージを表示する
- [ ] `cargo test` が全て通過する

## 制約事項

- 外部クレート不使用（標準ライブラリのみ）
- ベクトル要素の型は `f64`
- `unwrap()` は使用しない（テストコードは除く）
