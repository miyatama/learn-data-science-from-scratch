# プロダクト要求定義書

## プロダクトビジョンと目的

線形代数の基礎計算をRustで実装し、データサイエンスの学習における数学的基盤を理解・習得する。

## ターゲットユーザーと課題・ニーズ

- **ターゲット:** データサイエンスを学習中の開発者
- **課題:** 線形代数の概念を理論だけでなく実装を通じて理解したい
- **ニーズ:** ベクトル操作を実際にコードで書いて動作確認できる環境

## 主要な機能一覧

### Version 1.0.0

| 機能 | 説明 |
|------|------|
| ベクトル加算 | 同次元の2つのベクトルの各要素を加算する |
| ベクトル減算 | 同次元の2つのベクトルの各要素を減算する |
| スカラー乗算 | ベクトルの各要素にスカラー値を乗算する |
| 内積（ドット積） | 2つのベクトルの内積を計算する |
| 二乗和 | ベクトルの各要素の二乗和を計算する |
| マグニチュード | ベクトルの大きさ（ユークリッドノルム）を計算する |

## 成功の定義

- 各ベクトル操作が正確に計算できる
- Rustの型安全性を活かした実装になっている
- 単体テストで動作が検証されている

## ビジネス要件

- Rust言語で実装する
- CLIとして動作する（標準入力または引数でベクトルを受け取る）

## ユーザーストーリー

- 学習者として、ベクトルの加算・減算を実行し、結果を確認したい
- 学習者として、スカラー乗算を行い、ベクトルの拡大縮小を理解したい
- 学習者として、内積を計算し、ベクトル間の関係を理解したい
- 学習者として、二乗和とマグニチュードでベクトルの大きさを把握したい

## 受け入れ条件

- [ ] `vector_add([1,2,3], [4,5,6])` → `[5,7,9]`
- [ ] `vector_subtract([5,7,9], [4,5,6])` → `[1,2,3]`
- [ ] `scalar_multiply(2.0, [1,2,3])` → `[2,4,6]`
- [ ] `dot_product([1,2,3], [4,5,6])` → `32`
- [ ] `sum_of_squares([1,2,3])` → `14`
- [ ] `magnitude([3,4])` → `5.0`

## 機能要件

- 入力ベクトルの次元が不一致の場合はエラーを返す
- 浮動小数点数（f64）で計算する

## 非機能要件

- Rustの`cargo test`で全テストが通過すること
- コードは読みやすく、学習教材として参照できること
