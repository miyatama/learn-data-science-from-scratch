# ユビキタス言語定義

## ドメイン用語

| 日本語 | 英語 | 説明 |
|--------|------|------|
| ベクトル | Vector | 数値の順序付きリスト。`[1.0, 2.0, 3.0]` のように表現する |
| 次元 | Dimension | ベクトルの要素数 |
| スカラー | Scalar | 単一の数値。ベクトルに対する乗数として使用する |
| 内積 | Dot Product | 2つのベクトルの対応する要素の積の総和 |
| 二乗和 | Sum of Squares | ベクトルの各要素の二乗の総和 |
| マグニチュード | Magnitude | ベクトルの大きさ（ユークリッドノルム）。二乗和の平方根 |
| ノルム | Norm | ベクトルの長さを表す概念。本プロジェクトではL2ノルム（ユークリッドノルム）を指す |

## コード上の命名規則

| 概念 | コード上の名前 |
|------|--------------|
| ベクトル | `v`, `v1`, `v2`（引数）/ `Vec<f64>`（型） |
| スカラー | `scalar` |
| ベクトル加算 | `vector_add` |
| ベクトル減算 | `vector_subtract` |
| スカラー乗算 | `scalar_multiply` |
| 内積 | `dot_product` |
| 二乗和 | `sum_of_squares` |
| マグニチュード | `magnitude` |

## 英語・日本語対応表（CLIサブコマンド）

| サブコマンド | 機能 |
|-------------|------|
| `add` | ベクトル加算 |
| `sub` | ベクトル減算 |
| `scale` | スカラー乗算 |
| `dot` | 内積 |
| `sumsq` | 二乗和 |
| `magnitude` | マグニチュード |
