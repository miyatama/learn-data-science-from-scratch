# 技術仕様書

## テクノロジースタック

| カテゴリ | 技術 | バージョン |
|----------|------|-----------|
| 言語 | Rust | 1.70以上 |
| ビルドツール | Cargo | Rustに同梱 |
| 外部クレート | なし（標準ライブラリのみ） | - |

## 開発ツールと手法

| ツール | 用途 |
|--------|------|
| `cargo build` | ビルド |
| `cargo test` | ユニットテスト実行 |
| `cargo run` | CLIの実行 |
| `cargo clippy` | Lintチェック |
| `cargo fmt` | コードフォーマット |

## プロジェクト構成

```
04_linear-algebra/
├── Cargo.toml
└── src/
    ├── main.rs       # CLIエントリーポイント
    └── vector.rs     # ベクトル演算モジュール
```

## 技術的制約と要件

- 外部クレートは使用しない（標準ライブラリのみ）
- ベクトルの要素型は `f64` に統一する
- 次元不一致は `Result<T, String>` でハンドリングする

## パフォーマンス要件

- Version 1.0.0は学習目的のため、パフォーマンス要件は設けない
- 正確性・可読性を優先する
