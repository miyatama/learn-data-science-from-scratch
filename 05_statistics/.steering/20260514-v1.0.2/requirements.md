# 要求事項 - Version 1.0.2

## 変更・追加する機能の説明

### 1. 散らばり出力の拡張

現在の「範囲（最大値−最小値）」の出力を以下の3項目に拡張する。

- 最小値（min）
- 最大値（max）
- 数値の範囲（range = 最大値 − 最小値）

### 2. 相関に 3σ フィルタ後の統計値を追加

datas[0] の平均 ± 3σ の範囲内に収まるデータのみを使って、
共分散と相関係数を再計算して出力する。

## ユーザーストーリー

```
As a データサイエンス学習者
I want to  散らばりの詳細（最小値・最大値・範囲）を確認したい
So that    データの端の値を直感的に把握できる

As a データサイエンス学習者
I want to  外れ値を除いた 3σ 範囲内の相関を確認したい
So that    外れ値の影響を除いた相関の強さを比較できる
```

## 受け入れ基準

- [ ] 散らばりセクションに「最小値」「最大値」「数値の範囲」が出力される
- [ ] 相関セクションに「3σ範囲内の共分散」「3σ範囲内の相関係数」が出力される
- [ ] 3σ フィルタは datas[0] の mean ± 3 * std_deviation を基準にする
- [ ] `cargo build --release` が成功すること
- [ ] `cargo test` が全パスすること
- [ ] `cargo clippy` で警告ゼロ

## 制約事項

- 外部クレート追加禁止
- Version 1.0.1 の既存機能（ヘルプ・通常計算）は変更しない
