# 要求事項 - Version 1.0.1 ヘルプ機能実装

## 変更・追加する機能の説明

`-h` または `--help` オプションを渡したとき、Usage・パラメータ説明を表示して正常終了する。

## ユーザーストーリー

```
As a ユーザー
I want to  -h または --help を渡す
So that    コマンドの使い方とパラメータを確認できる
```

## 受け入れ基準

- [ ] `./statistics -h` でヘルプを表示して exit code 0 で終了する
- [ ] `./statistics --help` でヘルプを表示して exit code 0 で終了する
- [ ] ヘルプにはコマンドの Usage とパラメータ説明が含まれる
- [ ] ヘルプ以外の動作（JSON ファイル指定）は Version 1.0.0 と同一

## 制約事項

- 外部クレート追加禁止（引数解析ライブラリを新たに追加しない）
- `main.rs` の引数解析部分のみ変更する
