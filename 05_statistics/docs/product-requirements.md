# プロダクト要求定義書

## プロダクトビジョンと目的

統計学の基礎概念をRustで実装したCLIツール。
「Data Science From Scratch」の第5章（統計）に対応し、
データセットから代表値・散らばり・相関を計算・表示する。

## ターゲットユーザーと課題・ニーズ

| ターゲット | 課題 | ニーズ |
|-----------|------|--------|
| データサイエンス学習者 | 統計指標の計算方法を手を動かして学びたい | 実装を通じた理解の深化 |
| Rust学習者 | 数値計算をRustで実践したい | 型安全な数値処理の実装経験 |

## 主要な機能一覧

### Version 1.0.0

| カテゴリ | 機能 |
|---------|------|
| 代表値 | 平均値、中央値、分位数、最頻値 |
| 散らばり | 範囲、分散、標準偏差 |
| 相関 | 共分散、相関係数 |

## 成功の定義

- `./examples/statistics.json` を入力として受け取り、各統計量を正しく計算・出力できる
- Rustのコンパイルエラー・警告がゼロの状態でビルドできる
- 数値計算結果が Python の statistics / numpy による参照値と一致する

## ビジネス要件

- 学習用プロジェクトのため、シンプルさと可読性を優先する
- 外部クレートへの依存は最小限（serde_json のみ許可）

## ユーザーストーリー

```
As a データサイエンス学習者
I want to  JSON ファイルに含まれるデータセットを CLI に渡す
So that    平均・分散・相関係数などの統計量を一覧で確認できる
```

## 受け入れ条件

- [ ] `./statistics ./examples/statistics.json` で実行できる
- [ ] 代表値（平均値・中央値・25%分位数・75%分位数・最頻値）が表示される
- [ ] 散らばり（範囲・分散・標準偏差）が表示される
- [ ] 相関（共分散・相関係数）が表示される
- [ ] `datas` フィールドに 2 本のデータ列が含まれる場合、相関を計算する
- [ ] 無効な JSON またはファイル不存在時にエラーメッセージを表示して終了する

## 機能要件

### 入力フォーマット

```json
{
  "datas": [
    [<f64>, ...],
    [<f64>, ...]
  ]
}
```

- `datas[0]` : 1本目のデータ列（代表値・散らばり計算対象）
- `datas[1]` : 2本目のデータ列（相関計算対象）

### 出力フォーマット

```
=== 代表値 (datas[0]) ===
平均値      : <value>
中央値      : <value>
25%分位数   : <value>
75%分位数   : <value>
最頻値      : <value>

=== 散らばり (datas[0]) ===
範囲        : <value>
分散        : <value>
標準偏差    : <value>

=== 相関 (datas[0] vs datas[1]) ===
共分散      : <value>
相関係数    : <value>
```

## 非機能要件

- ビルド：`cargo build --release` で成功すること
- 実行速度：通常のデータサイズ（要素数 1,000 以下）で即時応答（1秒以内）
- エラー処理：パニックではなく `eprintln!` + `process::exit(1)` で終了
