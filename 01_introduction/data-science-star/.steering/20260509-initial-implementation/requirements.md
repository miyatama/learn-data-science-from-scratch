# 初回実装 要求事項

## 概要

データサイエンススター社の社内データ（ユーザー・交友関係）に対して統計量を算出するCLIアプリケーションの初回実装。

## 実装する機能

| ID | 機能 | 説明 |
|----|------|------|
| F-01 | ユーザーデータ読み込み | `data/users.json` をパースしてUserのVecを生成 |
| F-02 | 交友関係データ読み込み | `data/friendship.json` をパースして隣接リストを生成 |
| F-03 | 友人数集計 | 各ユーザーの友人数を算出して表示 |
| F-04 | 平均友人数算出 | ネットワーク全体の平均友人数を算出して表示 |
| F-05 | 友人の友人列挙 | 各ユーザーの2ホップ以内のユーザーを列挙して表示 |
| F-06 | 共通友人数算出 | 全ユーザーペアの共通友人数を算出して表示 |
| F-07 | 次数中心性算出 | 各ユーザーの次数中心性を算出して表示 |

## 受け入れ基準

- `cargo run` で正常に起動・実行できる
- `cargo clippy` で警告が出ない
- `cargo fmt` 適用済み
- `cargo test` がすべてパスする
- 各統計値が手動計算と一致する

## 制約事項

- `unwrap()` は使用しない
- 外部データベース・ネットワーク通信は使用しない
- 依存クレートは `serde` / `serde_json` のみ
