# 技術仕様書

## テクノロジースタック

| カテゴリ | 技術 | バージョン |
|---------|------|----------|
| 言語 | Rust | 2024 edition |
| ビルドツール | Cargo | Rust標準 |
| JSONパース | serde / serde_json | 最新安定版 |
| 実行形式 | CLIバイナリ | - |

## 開発ツールと手法

| ツール | 用途 |
|-------|------|
| cargo build | ビルド |
| cargo run | 実行 |
| cargo test | テスト実行 |
| cargo clippy | 静的解析 |
| cargo fmt | コードフォーマット |

## 依存クレート

```toml
[dependencies]
serde = { version = "1", features = ["derive"] }
serde_json = "1"
```

## 技術的制約と要件

- 外部データベース・ネットワーク通信は使用しない
- データはすべてJSONファイルから読み込む
- 実行時に全データをメモリ上に保持する（データ量が少ないため許容）
- 標準出力のみ使用（GUIなし）

## パフォーマンス要件

- 対象データは10ユーザー・12ペア程度の小規模データ
- 起動から結果出力まで1秒以内を目標
- メモリ使用量に特別な制約なし
