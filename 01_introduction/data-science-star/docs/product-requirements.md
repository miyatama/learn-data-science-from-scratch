# プロダクト要求定義書

## プロダクトビジョンと目的

データサイエンススター社の社内データ（ユーザー情報・交友関係）に対して統計量を算出し、組織内の人間関係ネットワークを定量的に把握することを目的とする。

## ターゲットユーザーと課題・ニーズ

### ターゲットユーザー
- データサイエンススター社の経営陣・HR担当者
- 社内ネットワーク分析に興味を持つデータアナリスト

### 課題・ニーズ
- 社員間の交友関係がどのように広がっているかを定量的に把握したい
- 特定の社員が何人の友人を持つかを簡単に確認したい
- ネットワーク全体の統計的傾向（平均友人数など）を把握したい

## 主要な機能一覧

1. **友人数の集計** - 各ユーザーの友人数（次数）を算出
2. **平均友人数の算出** - ネットワーク全体の平均友人数を算出
3. **友人の友人リスト** - 各ユーザーの「友人の友人」を列挙（重複・自身を除く）
4. **共通の友人数による親密度** - ユーザーペアの共通友人数を算出
5. **次数中心性の算出** - 各ユーザーの次数中心性（友人数 ÷ (全ユーザー数 - 1)）を算出
6. **給与と経験年数データの統計** - 将来拡張用（現バージョンでは対象外）

## 成功の定義

- ユーザーJSONと交友関係JSONを読み込み、正確な統計量をコンソールに出力できる
- 各統計値が手動計算と一致する

## ビジネス要件

- データはJSONファイルから読み込む
- 出力はコンソール（標準出力）への表示
- 外部データベースは使用しない

## ユーザーストーリー

- **US-01**: データアナリストとして、各社員の友人数を確認したい。なぜなら、ネットワークの中心人物を特定したいから。
- **US-02**: データアナリストとして、平均友人数を確認したい。なぜなら、ネットワークの密度を把握したいから。
- **US-03**: データアナリストとして、特定の社員の「友人の友人」を確認したい。なぜなら、間接的なつながりを把握したいから。
- **US-04**: データアナリストとして、各社員の次数中心性を確認したい。なぜなら、ネットワーク内での相対的な影響力を比較したいから。

## 受け入れ条件

- `users.json` と `friendship.json` を読み込んで処理できる
- 各ユーザーの友人数が正しく表示される
- ネットワーク全体の平均友人数が正しく表示される
- 各ユーザーの「友人の友人」リストが重複・自身を除いて表示される
- 各ユーザーの次数中心性が正しく算出・表示される

## 機能要件

| ID | 機能 | 説明 |
|----|------|------|
| F-01 | ユーザーデータ読み込み | `data/users.json` をパースしてユーザーリストを生成 |
| F-02 | 交友関係データ読み込み | `data/friendship.json` をパースして隣接リストを生成 |
| F-03 | 友人数集計 | 各ユーザーの友人数を算出して表示 |
| F-04 | 平均友人数算出 | ネットワーク全体の平均友人数を算出して表示 |
| F-05 | 友人の友人列挙 | 各ユーザーの2ホップ以内のユーザー（自身・直接友人を除く）を列挙 |
| F-06 | 共通友人数算出 | 任意ユーザーペアの共通友人数を算出して表示 |
| F-07 | 次数中心性算出 | 各ユーザーの次数中心性（友人数 ÷ (全ユーザー数 - 1)）を算出して表示 |

## 非機能要件

- **言語**: Rust
- **実行環境**: コマンドライン（cargo run）
- **データ形式**: JSON（`serde_json` クレート使用）
- **出力**: 標準出力
- **エラーハンドリング**: ファイル読み込み失敗時は適切なエラーメッセージを表示して終了
